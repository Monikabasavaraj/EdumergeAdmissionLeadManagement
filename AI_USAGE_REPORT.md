# AI Usage Report

## Purpose of AI Usage

AI tools were used as a development assistant during implementation of the Admission Lead Management prototype.

## Areas Where AI Assistance Was Used

- Breaking the assignment into backend, frontend and documentation tasks
- Designing the Django data model
- Drafting Django REST Framework serializers and API views
- Creating React pages and components
- Implementing search and filtering
- Implementing dashboard metrics
- Improving validation and edge-case handling
- Drafting project documentation

## Example Prompt Categories

Examples of prompts used during development included:

- Design Django models for admission leads, counsellors and follow-ups.
- Create REST API serializers and validation for lead management.
- Build a React dashboard for lead ageing, status and counsellor workload.
- Add search and filters to the lead listing.
- Add validation for duplicate leads and Lost-status reasons.
- Draft project architecture and setup documentation.

## Generated Code

AI assistance contributed to drafts and implementation ideas for:

- Django models
- REST Framework serializers
- API views and routing
- React pages and components
- Dashboard calculations
- Search and filtering logic
- Validation logic
- Documentation

The generated suggestions were integrated and modified to fit the actual project structure.

## Wrong or Incomplete AI Output

AI-generated code can make assumptions about an existing project structure or produce code that does not exactly match the application's current state.

Examples of issues encountered during development included:

- File locations and project-root assumptions needed correction.
- Frontend and backend paths needed to be aligned with the actual project structure.
- Generated code needed to be checked against the existing Django and React implementation.

## How Issues Were Identified and Fixed

Issues were identified by:

- Checking the actual project directory structure
- Running Django commands
- Reviewing the API and frontend integration
- Checking Git status and repository contents
- Manually verifying the generated implementation

The implementation was adjusted to match the actual project structure rather than relying on generated assumptions.

## Human Verification

AI suggestions were reviewed before being retained. The final project configuration, integration, debugging, testing, GitHub setup and submission preparation were manually verified.

## Limitations

AI assistance was treated as a development aid rather than an authority. Generated code and documentation were reviewed and adapted to the actual implementation.
