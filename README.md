# Edumerge Admission Lead Management System

## 📌 Overview
A full-stack admission lead management system developed using
Django REST Framework and React.

## 🛠️ Technologies
- Python
- Django
- Django REST Framework
- React.js
- JavaScript
- HTML
- CSS
- SQLite/MySQL

## ✨ Features
- Counsellor management
- Lead management
- Follow-up management
- REST API integration
- React frontend
- CRUD operations

## ⚙️ How to Run

### Backend
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver

### Frontend
npm install
npm start
